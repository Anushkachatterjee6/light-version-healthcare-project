    Project Methodology

    MRI Dataset → Validation → Preprocessing → Feature-Based Image Analysis → CNN Classification → Evaluation → Visualization

    Clinical-text classification, clustering, entity extraction, and ranking are separate educational analyses contained only in the Tutorial Lab.

    MRI Workspace

    Use the existing studio to select a supplied case, modality, and slices; it validates available local MRI assets before analysis. External MRI upload is not implemented because this local app has no secure persistence or a validated multi-format ingestion pipeline.

    Open MRI Workspace

    Image Viewer

    Local case metadata, modality switching, and axial slice selection are provided in the Image Analysis Studio. Axial slice matching is supported; multiplanar zoom/pan and arbitrary upload viewing remain incomplete.

    Open axial MRI viewer

    Segmentation

    Reference masks are displayed only when provided by local BraTS cases. The compact CNN is a classifier and does not emit a predicted segmentation mask; Dice/IoU are therefore not shown.

    Open CNN evaluation

    Classification

    Run the existing compact, patient-separated CNN classifier in the studio. It reports measured training/validation curves and held-out classification metrics only when labels are available.

    Run classification

    Clustering

    No standalone clustering application module is implemented. Educational clustering is intentionally accessible only through the dedicated Tutorial Lab.

    Clinical Text Analysis

    No standalone clinical-text application module is implemented. The bundled corpus is synthetic educational material and is only available through Tutorial Lab.

    Research Analytics

    No standalone analytics application module is implemented. MRI feature exploration remains in the dedicated Tutorial Lab.

    Case History

    No case-history database is included. The local case inventory is read-only; results can be exported from individual analyses.

    Model Evaluation

    CNN validation uses patient/case separation. The local data lacks a verified tumour-negative cohort, so unsupported clinical diagnostic metrics are not fabricated.

    Open CNN evaluation

    Project Overview and Architecture

    Manual MRI review is affected by image variability, modality coverage, tumour-region annotation availability, and the challenge of reproducibly extracting image features. This project connects frontend modules to FastAPI APIs, local NIfTI MRI processing, OpenCV SIFT/RANSAC visualization, TensorFlow CNN evaluation, scikit-learn feature/text models, and PNG/JSON result export.

    MRI branch: dataset → validation → preprocessing → feature extraction → image analysis → classification/evaluation → visualization. Text branch: synthetic or authorized text → TF-IDF → classification/clustering → entity extraction → ranking/disambiguation.

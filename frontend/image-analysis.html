SIFT detects distinctive local features in the MRI images. RANSAC removes geometrically inconsistent feature matches and retains robust correspondences.

Pipeline

MRI slices → preprocessing → SIFT keypoints → descriptors → feature matching → RANSAC → inlier matches → visualization

SIFT

RANSAC

T5 — CNN classification

CNN Analysis

Run the same compact training and evaluation workflow as the tutorials dashboard, using local cases with both FLAIR MRI and reference segmentation labels.

Input and training

Cases and slices are selected automatically from the local labeled dataset. The existing demo uses 32 × 32 model inputs, up to eight sampled slices per case and three training epochs, with different patients reserved for validation.

Classification output

Displays actual input images, available reference masks, class labels and model scores. This classifier does not generate segmentation masks. Each run trains a fresh demo model; saved weights are not loaded or changed.

The SIFT case/modality/slice selectors apply only to SIFT. This CNN endpoint does not accept uploads or a single selected image; no uploaded image is silently replaced with demo data. Dataset and training settings are fixed by the existing endpoint.
